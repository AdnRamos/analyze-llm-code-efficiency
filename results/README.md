# Results

Generated files — do not edit by hand; `python run.py analysis` (or `python run.py paper`) recreates them.
Arquivos gerados — não editar à mão; `python run.py analysis` os recria.

| File | Generated by | Content |
|---|---|---|
| `statistics/numeros.json` | `analysis/statistics.py` | every number cited in the paper (acceptance with Wilson CIs, time, memory, tests, effect sizes, correlations, GEE, contamination, attrition, judge drift) |
| `statistics/tabelas.tex` | `analysis/statistics.py` | every LaTeX table and figure coordinate, between `%%BEGIN <label>` / `%%END <label>` |
| `statistics/posthoc.csv` | `analysis/statistics.py` | every pairwise post hoc comparison (metric, factor, pair, statistic, p, Holm p) |
| `statistics/ESTATISTICA.md` | `analysis/statistics.py` | readable summary |
| `glmm/glmm_or.csv` | `analysis/glmm.R` | odds ratios of the mixed model (Wald 95% CI, p) |
| `glmm/glmm_lrt_fatores.csv`, `glmm/glmm_lrt_interacoes.csv` | `analysis/glmm.R` | likelihood-ratio tests of each factor and of each two-way interaction |
| `glmm/glmm_resumo.txt` | `analysis/glmm.R` | n, random-effect SD, intraclass correlation, convergence, versions |
| `glmm/tab_glmm.tex` | `analysis/glmm.R` | LaTeX table of the paper |
| `figures/generation_validation/*.png` | `pipeline/3_generate/validate_responses.py` | categories of the generated responses per model and language |
